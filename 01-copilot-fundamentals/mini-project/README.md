# Mini Project

This mini project is designed to give hands-on practice with Copilot fundamentals in a small, self-contained exercise.

## Structure

- `src/` - source code for the project
- `tests/` - automated tests for validating functionality
- `.github/copilot-instructions.md` - guidance for Copilot use in the mini project

## Objectives

- Practice building and testing a simple Python tool
- Use Copilot to accelerate implementation workflows
- Document requirements and tasks clearly
